# Menus & social links

← [Back to README](../README.md)

## Main navigation

**Appearance → Menus.**

- If no menu exists yet: click **create a new menu**, name it anything,
  check **Primary Menu** under "Menu Locations", then add pages from the
  left-hand panel and **Save Menu**.
- To add a page: tick it in the "Pages" panel on the left → **Add to Menu**.
- To remove a page: expand it in the menu list on the right → **Remove**.
- Drag items up/down to reorder them.

If no menu is assigned to "Primary Menu", the site falls back to a fixed
Home/Articles/About/Subscribe menu — so the header never breaks — but you
have full control the moment you assign one.

## Footer links

The footer has three link columns. Each one is its own menu location, so
they can be edited independently:

**Appearance → Menus** → create/edit a menu → under **Menu Locations**,
assign it to **Footer Column 1**, **Footer Column 2**, or **Footer Column 3**.

Column headings ("Company", "Resources", "Support") are editable at
**Appearance → Customize → ARR Theme Settings → Footer**.

Until you assign your own menu to a column, it shows the original approved
links for that column — nothing goes blank.

## Social media icons

**Appearance → Customize → ARR Theme Settings → Social Media Links.**

Paste a URL into any of X (Twitter), LinkedIn, Facebook, YouTube, Instagram,
or an email address for the mail icon. **Only platforms with a URL filled
in show an icon** — leave the rest blank and they simply don't appear. If
every field is blank, the whole social row is hidden.
